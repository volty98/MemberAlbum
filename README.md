# MemberAlbum

Bludit plugin. メンバーが投稿トークンを使用して画像をアップロードできるギャラリープラグインです。

## セットアップ手順

### 1. プラグインのインストール
このプラグインを Bludit の `bl-plugins/` ディレクトリに配置してください。

### 2. **重要** - Album ページの作成

このプラグインが機能するには、**スラグが `album` のページを作成する必要があります**。

> ⚠️ **必須**: Bludit の管理画面で新しいページを作成し、以下の設定を確認してください：
> - **ページのスラグ**: `album` （完全に一致している必要があります）
> - ページの内容は空でも構いません。プラグインがギャラリーとアップロードフォームを自動的に追加します。

この設定がないと、プラグインのギャラリーとアップロードフォームは表示されません。

### 3. 管理画面でトークンを発行

- Bludit の管理画面 → プラグイン設定 → MemberAlbum
- ユーザー名を入力して「トークン発行」ボタンをクリック
- 発行されたトークンをコピーしてメンバーに配布

## 使い方

### 管理者向け
1. MemberAlbum プラグインの設定画面を開く
2. ユーザー名を入力してトークンを生成
3. 発行されたトークンをメンバーに配布

### メンバー向け
1. Album ページにアクセス
2. 下部の「画像投稿」フォームでトークンを入力
3. 画像ファイルを選択して投稿
4. 投稿完了メッセージが表示されたら完了

## トラブルシューティング

### ギャラリーとアップロードフォームが表示されない

確認事項：
- Bludit の管理画面でページのスラグが正確に **`album`** であることを確認してください
- スラグが `Album`（大文字）や `albums`（複数形）などになっていないか確認してください
- ページが公開状態になっているか確認してください

### アップロードが失敗する

確認事項：
- 入力したトークンが正しいか確認してください
- アップロード画像の形式が対応フォーマット（JPEG、PNG、WebP）であることを確認してください
- ファイルサイズがサーバーの制限に引っかかっていないか確認してください

## 対応フォーマット

- JPEG
- PNG
- WebP
